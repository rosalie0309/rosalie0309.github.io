# Portfolio — Rosalie Corine Nkounghawe Tomeyum

Site personnel : **https://rosaliedomaine.com**

Site statique (HTML / CSS / JavaScript, sans framework), hébergé sur GitHub Pages.

## Structure
```
index.html              Page unique (toutes les sections)
assets/css/style.css    Styles + thèmes clair/sombre (variables CSS)
assets/js/main.js       Thème, menu mobile, onglets, animations, formulaire
assets/img/             hero.webp (illustration), favicon.svg
assets/cv/              CV téléchargeable
CNAME                   Domaine personnalisé pour GitHub Pages
```

## Modifier le contenu
Tout le texte est dans `index.html`. Pour mettre à jour le CV, remplacer le PDF dans `assets/cv/` en gardant le même nom.

## Prévisualiser en local
```bash
python -m http.server 8000
# puis ouvrir http://localhost:8000
```
